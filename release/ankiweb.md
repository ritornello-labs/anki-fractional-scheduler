Pace new cards below whole-number daily limits—for example, one new card every three days—using Anki's Today-only limits.

## See it in Anki

![Preview a one-every-three-days schedule, then inspect the grouped-deck balance queue](https://ritornello.dev/media/ankiweb/2026-10-07-v7/fractional-scheduler/schedule.gif)

The demo sets a language trickle of one card every three days, previews four populated language subdecks, then shows their balanced queue.

## Features

- Every-N-days and day-of-week schedules.
- Exact decks or wildcard groups, with ordered include/exclude rules. Prefix a rule with `!` to exclude it; a later match can add it back.
- A deck picker that adds multiple selected rules at once.
- Exact and picker-created subtree targets that follow deck renames.
- A 14-day preview, stable staggering, and balance-first scheduling for grouped decks.
- Optional deck-health badges for blocked limits or empty new-card queues.
- Apply Today-only limits on profile open, collection open, or before sync.

Requires Anki 2.1.55 or newer.
